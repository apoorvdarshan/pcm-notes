# iPhone Duo screenshots (optional)

PNGs in this folder go up as the `APP_IPHONE_DUO` set with the other App Store
screenshots when `IOS_UPLOAD_SCREENSHOTS` is on, in file-name order, as RGB
copies: the outer screen at 1398×2034 or the inner screen at 2007×2853 (one set
takes both). `01`–`04` show the inner screen and `05-outer-reader` the outer
screen. Without PNGs here, the iPhone Duo set in App Store Connect is left
alone. See [store/README.md](../../../../README.md#screenshots).
