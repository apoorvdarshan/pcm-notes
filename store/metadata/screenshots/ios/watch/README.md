# Apple Watch screenshots (optional)

None yet. PNGs in this folder go up with the other App Store screenshots when
`IOS_UPLOAD_SCREENSHOTS` is on, in file-name order, as RGB copies. Each frame's
size picks its set: 416×496 `APP_WATCH_SERIES_10`, 422×514 or 410×502
`APP_WATCH_ULTRA`, 396×484 `APP_WATCH_SERIES_7`, 368×448 `APP_WATCH_SERIES_4`,
312×390 `APP_WATCH_SERIES_3`. Without PNGs here, the Watch sets in App Store
Connect are left alone. See [store/README.md](../../../../README.md#screenshots).
