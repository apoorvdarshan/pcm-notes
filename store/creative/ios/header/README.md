# Product page header image

Empty: PCM Notes has no header image yet, so this slot is left alone. To use it,
put one PNG of exactly 3840×1646, without alpha, in this folder and turn on
`IOS_UPLOAD_CREATIVE_ASSETS`: the release uploads it to the Asset Library once,
sends it to App Review in a submission of its own, and places it on the
version's en-US page once Apple approves it. Give a changed image a new file
name. See [store/README.md](../../../README.md#header-and-search-results-images-ios).
