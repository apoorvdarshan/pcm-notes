# Search results image

[`pcm-notes-search.png`](pcm-notes-search.png) is the 1920×1280 RGB search
results image. When `IOS_UPLOAD_CREATIVE_ASSETS` is enabled, the release uploads it
to the Asset Library once, sends it to App Review in a submission of its own,
and places it on the version's en-US page once Apple approves it. Give a changed
image a new file name. See [store/README.md](../../../README.md#header-and-search-results-images-ios).
